# FAQ

## Does a browser need to support Anzer?

No. The intended compiler output is HTML, CSS, and JavaScript that browsers already understand.

## Is Anzer a replacement for HTML, CSS, and JavaScript?

The project explores a unified authoring syntax, not a replacement for the web standards themselves. Those standards remain the output target.

## Is Anzer implemented?

Not yet. This repository is currently documentation and design groundwork.

## Is the syntax fixed?

No. The examples are provisional until the specification is approved.

## Is Anzer free?

The intention is to develop it as an open-source project. The repository uses the MIT license.
