# Language Overview

Anzer is planned as a source language for web pages and applications.

A source file has the extension `.anzer`. The compiler is expected to translate source constructs into standard web assets.

The initial design focuses on three concerns:

- **Structure:** page elements and content.
- **Style:** visual properties and layout.
- **Behavior:** events and client-side interaction.

The language is not yet finalized. The sample syntax in this repository is illustrative and may change.
